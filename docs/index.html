How to Use & Upload Theme

Installation, XML replacement, domain license verification, and mandatory static pages

A Upload XML Template
  1. Log into your Blogger Dashboard (blogger.com).
  2. In the left sidebar, click Theme.
  3. Click the dropdown arrow next to Customize > select Edit HTML (or Restore > upload iQplay-premium.xml).
  4. If using Edit HTML: Press Ctrl + A to select all code, delete it, and paste the entire XML content from the file.
  5. Click the orange Save icon in the top right corner.
B Domain License Registration

iQPlay features an automated domain security module. Before previewing, ensure your domain is licensed:

C Create Required Static Blank Pages

The theme routes user actions, video playback, and watchlist bookmarks via dedicated Blogger pages. Go to Blogger Dashboard > Pages > New Page and publish the following pages with blank HTML:

Page Title Generated URL Slug Functionality Page Content
Details /p/details.html Movie & series overview, cast, season list, ratings, backdrop Leave Blank
Player /p/player.html Multi-server video player, episode drawer, downloads, sandbox toggle Leave Blank
Library /p/library.html Personal saved watchlist, browsing history, and bookmark manager Leave Blank
About Us /p/about-us.html Site branding, mission statement & team info Configured via Layout Widget
Disclaimer /p/disclaimer.html DMCA, copyright compliance, non-hosting streaming notice Configured via Layout Widget
Privacy Policy /p/privacy-policy.html Cookies, ad policy, Supabase user privacy credentials Configured via Layout Widget

Layout Guide & Widget Configuration

How to configure TMDb API, Hero Slider, Video Rails, and Source Providers in Blogger Layout

TMDb API Config Widget Section: tmdb-api-config

The template communicates with TMDb v3 REST endpoints asynchronously. Add an HTML/JavaScript widget inside this section with your TMDb API key:

<script>
  window.apiKey = "YOUR_TMDB_V3_API_KEY";
</script>
Hero Carousel Slider Section: image-carousel

Displays full-bleed backdrop slides with title logos, ratings, genre tags, and direct Play & Watchlist buttons. Simply put the TMDb endpoint query in a Text Widget:

movie/popular

Or use trending/all/day for top trending daily titles.

Category Rails & Rows Section: tmdb-section-1

Create endless curated categories by adding HTML widgets. The Widget Title will be displayed as the rail header (e.g., Action Movies, Crime Series), while the content holds the endpoint:

Crime Series:
discover/tv?with_genres=80&sort_by=popularity.desc
Action Movies:
discover/movie?with_genres=28&sort_by=popularity.desc
Multi-Server Streaming Config Section: video-sources

Configured with failover servers. The player dynamically substitutes ${id}, ${season}, and ${episode}:

Server 1 (VidSrc): https://vidsrc.cc/v2/embed/movie/${id}
Server 2 (Videasy): https://player.videasy.net/tv/${id}/${season}/${episode}

Creating a Post (Full HTML View Template)

          
Complete markup schema including backdrop, poster, iframe, #extra-meta, #episodes-data, #download-data, and #celebrity-data

        

      


      

        

          While iQPlay supports fully automated TMDb fetching by ID, you can also publish custom manual articles or overrides in Blogger. Switch your post editor to HTML view and paste this complete schema:
        


        
        

          
<!-- iQPlay Universal Post Schema -->
<div class="iqplay-post-entry">

  <!-- 1. Backdrop & Poster Images -->
  <div class="iq-hero-art">
    <img id="post-backdrop" src="https://image.tmdb.org/t/p/w1280/backdrop.jpg" alt="Backdrop Banner" style="display:none;" />
    <img id="post-poster" src="https://image.tmdb.org/t/p/w500/poster.jpg" alt="Official Poster" class="main-poster" />
  </div>

  <!-- 2. Primary Video Stream / Embed Iframe -->
  <div class="iq-player-container">
    <iframe id="main-stream-player" src="https://vidsrc.cc/v2/embed/movie/1022789" frameborder="0" allowfullscreen="true" scrolling="no"></iframe>
  </div>

  <!-- 3. Extra Meta Data (JSON Block) -->
  <div id="extra-meta" style="display:none;">{
    "tmdb_id": 1022789,
    "imdb_id": "tt11198330",
    "type": "movie",
    "release_year": "2024",
    "runtime": "100 min",
    "rating": "7.8",
    "quality": "4K Ultra HD",
    "genres": ["Animation", "Family", "Adventure", "Comedy"],
    "synopsis": "Teenager Riley is experiencing new emotions inside Headquarters, including Anxiety, Envy, Ennui, and Embarrassment."
  }</div>

  <!-- 4. Episodes Multi-Server Data (For Series / Anime) -->
  <div id="episodes-data" style="display:none;">[
    {
      "season": 1,
      "episode": 1,
      "title": "Pilot: The Journey Begins",
      "servers": {

             Supabase Cloud Auth & Comments
          

          

            iQPlay connects directly to Supabase REST endpoints for clientless zero-server user login, watchlist sync across devices, and live episode discussions:
          

          

            const { createClient } = supabase;

            const client = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

  • Custom avatars: Person, Animal, Animation, and Emoji categories
